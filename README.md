# Dova landing page

Static marketing site for Dova.

## Live

https://dova-landing.hugheszane-com.workers.dev

## Local

```bash
python3 -m http.server 4173
```

Open http://127.0.0.1:4173/

## Deploy (Cloudflare Worker)

```bash
npx wrangler deploy
```

Requires `CLOUDFLARE_API_TOKEN` and account access.
